---
title: createBrowserClient
description: Bind a generated browser endpoint tree to a WordPress origin.
---

Import `createBrowserClient` from `kizlo/browser`. `createKizloClient` from `kizlo` is an alias with the same options.

```ts
createBrowserClient({ url, endpoints, getToken?, cartSession?, onResponse? })
```

`url` and nonempty generated `endpoints` are required. `getToken` supplies a fresh user JWT or `null`. `cartSession` reads and stores the native Cart-Token. `onResponse` receives response headers.

The returned value is the callable endpoint tree itself. It has no `.client` wrapper or `.call()` variant. Types come from the endpoint value; React hooks also use the generated browser registry. See [Client](/docs/concepts/client) for complete examples and [migration](/docs/concepts/migration-v1) for old calls.
