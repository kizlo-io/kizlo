`WP_CallOptions` is the optional second argument on every generated WordPress endpoint. Its values apply only
to that request.

<AutoTypeTable
  path="../packages/kizlo/src/wordpress/types.ts"
  name="WP_CallOptions"
/>

| Option | Type | Effect |
| --- | --- | --- |
| `headers` | `Record<string, string>` | Add or override request headers. |
| `signal` | `AbortSignal` | Cancel the request from an existing controller or signal. |

```ts
const controller = new AbortController()

await context.wordpress.kizlo.postTypes.post.retrieve(
  { params: { identifier: "featured" } },
  {
    headers: { "X-Request-Source": "homepage" },
    signal: controller.signal,
  },
)
```

Pass an empty input object first when an endpoint has no required input but still needs call options.

Kizlo adds no timeout signal by default, so framework fetch deduplication can apply to eligible reads.
To set a deadline, pass `{ signal: AbortSignal.timeout(5_000) }`. This replaces the removed `timeout` option.
