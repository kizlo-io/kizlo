---
title: kizlo_register_spec_schema
icon: Function
description: Register a reusable schema for described WordPress routes.
---

`kizlo_register_spec_schema` adds a named schema to Kizlo's introspection document. Reference it from route
inputs and responses to define a shared shape once.

## Parameters

```php
kizlo_register_spec_schema(string $id, array $schema): void
```

| Parameter | Type | Description |
| --- | --- | --- |
| `$id` | `string` | Globally unique, vendor-qualified ID such as `acme.order`. |
| `$schema` | `array` | Schema written in Kizlo's contract vocabulary. |

The `kizlo.*`, `post-types.*`, and `taxonomies.*` prefixes are reserved for Kizlo core. A third-party plugin
must use its own vendor or domain prefix.

<Callout type="warn">
  Write `'$ref'` and `'$extends'` with single quotes. PHP interpolates these keys inside double-quoted strings.
</Callout>

## Returns

`void`. The schema appears under `schemas` in `GET /kizlo/v1/introspect` after validation.

## Example

```php title="wp-content/plugins/acme-orders/schemas.php"
kizlo_register_spec_schema('acme.order', [
    'type'       => 'object',
    'properties' => [
        'id'     => ['type' => 'integer', 'required' => true],
        'status' => [
            'type'     => 'string',
            'required' => true,
            'enum'     => ['pending', 'complete'],
        ],
    ],
]);
```

Use `['$ref' => 'acme.order']` in a
[`kizlo_register_spec_route`](/docs/php/functions/register-spec-route) response.
