Kizlo talks to WordPress. Install the plugin on the WordPress you want to use, then pick your
framework below to wire it into your app.

<Callout>
  Just trying it out? For local dev, the CLI runs WordPress in Docker with the plugin and
  credentials set up for you, so you can skip the steps below.
</Callout>

## Install the WordPress plugin

Download the latest Kizlo plugin, then in WP Admin go to **Plugins → Add New → Upload Plugin**,
choose the zip, and **Activate**.

<DownloadButton plugin="kizlo" />

Once activated, the plugin keeps itself up to date from within WordPress, so there's no need to
come back here for future versions. The CLI handles credentials from here.
