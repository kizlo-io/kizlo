---
title: Next.js
description: Read public WordPress content in Next.js without an API proxy.
---

Complete [Installation](/docs/installation), then set `NEXT_PUBLIC_KIZLO_WP_URL` to the WordPress origin. This value is public; the Application Password is separate and private.

```ts title="src/lib/kizlo/client.ts"
import { createBrowserClient } from "kizlo/browser"
import { introspection } from "./generated/introspection.browser"

export const client = createBrowserClient({
  url: process.env.NEXT_PUBLIC_KIZLO_WP_URL!,
  endpoints: introspection,
})
```

## Render a post

```tsx title="src/app/blog/[slug]/page.tsx"
import { notFound } from "next/navigation"
import { client } from "@/lib/kizlo/client"

type Props = { params: Promise<{ slug: string }> }
export default async function PostPage({ params }: Props) {
  const { slug } = await params
  const { data, error, status } = await client.kizlo.content.post.retrieve({ params: { identifier: slug } })
  if (status === 404) notFound()
  if (error) throw error
  return <article>
    <h1>{data.title.rendered}</h1>
    <div dangerouslySetInnerHTML={{ __html: data.content.rendered }} />
  </article>
}
```

The same client works in a Client Component. Use the [token getter](/docs/concepts/client#customer-sessions) for user requests. No catch-all API route is required.

## Add metadata and events

`createRootMetadata`, `createRootViewport`, `createManifestRoute`, `createRobotsRoute`, and sitemap helpers remain in `kizlo/nextjs/server`. Pass the direct public client to those helpers. For a post head, call `deserializeSeo(data.kizlo.seo)` from `kizlo` before `createPageMetadata`; check that `kizlo` is non-null first.

Receive optional cache invalidation through [a standalone signed webhook](/docs/concepts/integration#receive-signed-events). Keep service operations in a separate [server client](/docs/concepts/client#service-client).
