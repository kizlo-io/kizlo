## Browser client

Pass your WordPress URL and generated browser endpoints. Public reads also work during SSR with this credentials-free client.

```ts title="src/lib/kizlo/client.ts"
import { createBrowserClient } from "kizlo/browser"
import { introspection } from "./generated/introspection.browser"

export const client = createBrowserClient({
  url: "https://cms.example.com",
  endpoints: introspection,
})
```

```ts
const result = await client.kizlo.content.post.retrieve({ params: { identifier: "hello-world" } })
if (result.error) {
  console.error(result.error.code, result.status)
} else {
  console.log(result.data.title.rendered)
}
```

Results contain `data`, `error`, `status`, and response `headers`. Errors retain WordPress codes. Use `requireData(result)` from `kizlo` to throw an error from a route loader instead of branching.

## Customer sessions

Supply a fresh provider token for each request. Return `null` only when the visitor is signed out. A token getter failure and a rejected token remain errors.

```ts
const client = createBrowserClient({
  url: "https://cms.example.com",
  endpoints: introspection,
  getToken: () => session.getToken(),
  cartSession: {
    get: () => sessionStorage.getItem("cart"),
    set: (token) => token ? sessionStorage.setItem("cart", token) : sessionStorage.removeItem("cart"),
  },
})
```

Read `client.woocommerce.store.cart.retrieve()` once to obtain a signed Cart-Token before cart writes. Clear your stored cart token on logout or account switches. WordPress checks its owner on every request. Never share this storage between SSR visitors.

Configure [authentication and browser origins](/docs/concepts/authentication) in WordPress. Requests omit cookies; signed tokens carry the session.

## Service client

Import service operations only from `kizlo/server`. Keep credentials in server environment variables, and use the full generated projection.

```ts title="src/lib/kizlo/admin.ts"
import { createServerClient } from "kizlo/server"
import { introspection } from "./generated/introspection"

export const admin = createServerClient({
  endpoints: introspection,
  credentials: {
    url: process.env.KIZLO_WP_URL!,
    username: process.env.KIZLO_WP_USERNAME!,
    password: process.env.KIZLO_WP_APP_PASSWORD!,
  },
})
```

The service client makes HTTP requests to WordPress. It does not impersonate a customer. Use visitor tokens for customer operations.

## Cancellation and React

Pass `{ signal: AbortSignal.timeout(5000) }` as the second call argument. For an endpoint without input, pass `undefined` first.

React applications can pass the direct browser client to [`KizloProvider`](/docs/reference/functions/kizlo-provider) and read it with [`useKizloContext`](/docs/reference/functions/use-kizlo-context). Import the generated browser module in the TypeScript program to register the exact hook type.
