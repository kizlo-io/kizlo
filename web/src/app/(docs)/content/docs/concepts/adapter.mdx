---
title: Server utilities
icon: Plug
description: Use explicit server utilities without an integration container.
---

Import cookie, geo, logging, mail, and settings utilities from `kizlo/server`. Framework helpers remain under their framework's `/server` entry.

Use the native framework to own request context and authorization. Pass concrete dependencies to your own functions. Kizlo no longer composes auth, CAPTCHA, middleware, or procedure adapters.

JWT verification and CAPTCHA secrets belong in WordPress settings. See [authentication](/docs/concepts/authentication). Browser code supplies a token and calls the final endpoint through the [direct client](/docs/concepts/client).
