Bring your Advanced Custom Fields into any JavaScript runtime.

== Description ==

Publishes Advanced Custom Fields values under kizlo.custom.acf on every managed post type and taxonomy that has ACF field groups, typed in the Kizlo introspection contract.

Requires the Kizlo core plugin and Advanced Custom Fields to be active.
